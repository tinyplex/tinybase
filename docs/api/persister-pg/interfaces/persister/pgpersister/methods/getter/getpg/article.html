getPg

The getPg method returns a reference to the database connection the Store is being persisted to.

getPg(): Pool | Client
returnsPool | Client

A reference to the pg Pool or Client.

Example

This example creates a Persister object against a newly-created Store and then gets the database connection back out again.

import {Pool} from 'pg';
import {createStore} from 'tinybase';
import {createPgPersister} from 'tinybase/persisters/persister-pg';

const pool = new Pool({
  connectionString: 'postgres://localhost:5432/tinybase',
});
const store = createStore().setTables({pets: {fido: {species: 'dog'}}});
const persister = await createPgPersister(store, pool, 'my_tinybase');

console.log(persister.getPg() == pool);
// -> true

await persister.destroy();
await pool.end();
