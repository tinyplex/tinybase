SqliteNodePersister

The SqliteNodePersister interface represents a Persister that lets you save and load Store data to and from a local SQLite database.

You should use the createSqliteNodePersister function to create a SqliteNodePersister object.

It is a minor extension to the Persister interface and simply provides an extra getDb method for accessing a reference to the database the Store is being persisted to.
