jsonParseWithUndefined

The jsonParseWithUndefined function parses JSON that was serialized with the jsonStringWithUndefined function, restoring the undefined values within it.

jsonParseWithUndefined(json: string): any
TypeDescription
jsonstring

The JSON to parse.

returnsany

The parsed object, with its undefined values restored.

Use it to read the MergeableContent or MergeableChanges of a MergeableStore that were serialized with that function, so that the Cells and Values they delete stay deleted.

Example

This example parses JSON that has an undefined value.

import {jsonParseWithUndefined} from 'tinybase';

const pet = jsonParseWithUndefined('{"species":"dog","color":"￼"}');
console.log(pet);
// -> {species: 'dog', color: undefined}
console.log(Object.keys(pet));
// -> ['species', 'color']
